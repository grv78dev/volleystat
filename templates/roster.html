Importa Rosa da CSV

Come preparare il file CSV

  1. Crea un file .csv (Excel: Salva con nome → CSV UTF-8).
  2. La prima riga deve contenere esattamente le intestazioni:
    numero,nome,ruolo
  3. Ogni riga successiva rappresenta un atleta.
  4. I numeri di maglia già presenti nella rosa vengono ignorati.

Codici ruolo

PPalleggiatore OOpposto BBanda — Schiacciatore CCentrale LLibero UUniversale (default se omesso)

numero,nome,ruolo
10,Mario Rossi,P
5,Luca Bianchi,B
3,Andrea Verdi,C
1,Giorgio Neri,L
7,Francesco Gialli,O
12,Matteo Blu,U

Il file non verrà modificato. I dati verranno aggiunti alla rosa esistente.
